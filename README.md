# 全員、写れ！

Three.js と TypeScript で制作した **3Dドタバタ集合写真撮影ゲーム** です。

結婚式・修学旅行・社内運動会・南国ビーチで、勝手に動き回る被写体たちをカメラ操作で誘導しながら、最高の1枚（または爆笑の1枚）を激写します。

**公開プレイページ**: https://kogetyadot.github.io/zenin-utsure/

## 主な特徴

- **カメラ操作が被写体を動かす**: レンズを向ける方向・角度・ズームに応じて、目立ちたがり・恥ずかしがり・ひょっこり・ジャンパー・おせっかい・うっかり・主役の7タイプのNPCが連鎖的に反応します。
- **制御されたドタバタ物理＆バカゲー要素**:
  - 押し合い・段差からのよろめき＆転倒ドミノ・助け合いパイルアップ・ぐらぐら肩車
  - 衝撃で帽子・麦わら帽子・ベール・着ぐるみ耳が宙に舞う＆アッカンベー変顔テロ＆爆風メガくしゃみ
  - 突撃してくる目立ちたがりをカメラ振りで「すってんころりん」させるカウンター
- **全4ステージ（固有ギミック＆乱入キャラ付き）**:
  1. **ガーデンウェディング**（13人）— 蝶ネクタイ付き暴走ハト乱入
  2. **修学旅行・古都の石段**（14人）— 鹿せんべいをくわえた奈良のシカ乱入
  3. **社内運動会・グラグラ表彰台**（15人）— 段差の激しい1〜3位表彰台・くす玉パッカーン・暴走大玉ボウリング
  4. **南国ビーチ・大波サマー**（13人）— 周期的なざっぱーん大波スリップ＆巨大ビーチボール乱入
- **厳密な3D採点＆「🤣 爆笑度」メーター＆ポラロイド現像**: 4:3ファインダー画角に基づく100点写真スコアと0〜100%爆笑度を同時採点。タブロイド風見出し・コメディ賞シール付きポラロイドPNGをそのまま保存できます。
- **オフライン完結のWeb Audio音響**: 4ステージ別のオリジナルBGM（庭園スウィング／古都マーチ／運動会マーチ／南国スティールドラム・カリプソ）、一眼レフ風シャッター音、各種ドタバタ効果音をプロシージャル合成。
- **PC・スマートフォン両対応**: ドラッグ／スワイプ、ピンチ／ホイールズーム、モバイル縦画面向け自動画角補正に対応。

## セットアップ＆起動

```bash
npm install
npm run dev
```

プロダクションビルド：

```bash
npm run build
npm run preview
```

## 操作方法

| 操作 | PC | モバイル |
| --- | --- | --- |
| 構図・回り込み | ドラッグ / `WASD` / 矢印キー | 1本指スワイプ |
| カメラパン | 右ドラッグ / `Shift` + ドラッグ | — |
| ズーム | ホイール / `Q` `E` / スライダー | 2本指ピンチ / スライダー |
| 「はい、チーズ！」 | `Space` / ボタン | ボタン |
| シャッター | `Enter` / シャッターボタン | シャッターボタン |
