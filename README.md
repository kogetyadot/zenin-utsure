# 全員、写れ！

Three.js と TypeScript で制作した **3Dドタバタ集合写真撮影ゲーム** です。

結婚式や修学旅行の記念写真で、勝手に動き回る被写体たちをカメラ操作で誘導しながら、最高の1枚（または爆笑の1枚）を激写します。

## 主な特徴

- **カメラ操作が被写体を動かす**: レンズを向ける方向・角度・ズームに応じて、目立ちたがり・恥ずかしがり・ひょっこり・ジャンパー・おせっかい・うっかり・主役の7タイプのNPCが連鎖的に反応します。
- **制御されたドタバタ物理**: 押し合い、ひな壇／石段からのよろめき・転倒ドミノ、助けようとして巻き込まれるパイルアップ、後ろから顔を出す肩車アクションを搭載。
- **2つのステージ**:
  - **ガーデンウェディング**（13人）
  - **修学旅行・古都の石段**（14人）
- **厳密な3D採点＆ポラロイド現像**: 4:3ファインダー画角に基づく3本レイ遮蔽判定・見切れ・表情・構図・シャッターチャンスの100点採点、動的キャプション、8種のコメディ賞、ポラロイド風PNG保存機能を搭載。
- **オフライン完結のWeb Audio音響**: ステージ別BGM、一眼レフ風シャッター音、各種効果音・ファンファーレをプロシージャル合成。
- **PC・スマートフォン両対応**: ドラッグ／スワイプ、ピンチ／ホイールズーム、モバイル縦画面向け自動画角補正に対応。

## セットアップ＆起動

```bash
npm install
npm run dev
```

プロダクションビルド：

```bash
npm run build
npm run preview
```

## 操作方法

| 操作 | PC | モバイル |
| --- | --- | --- |
| 構図・回り込み | ドラッグ / `WASD` / 矢印キー | 1本指スワイプ |
| カメラパン | 右ドラッグ / `Shift` + ドラッグ | — |
| ズーム | ホイール / `Q` `E` / スライダー | 2本指ピンチ / スライダー |
| 「はい、チーズ！」 | `Space` / ボタン | ボタン |
| シャッター | `Enter` / シャッターボタン | シャッターボタン |
